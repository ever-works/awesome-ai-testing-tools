- [Checksum](https://checksum.ai/) - Checksum automatically generates end-to-end tests from user sessions and production traffic using AI. - [Diffblue Cover](https://diffblue.com/) - Diffblue Cover is an AI-powered unit test generation tool for Java applications. - [Launchable](https://www.launchableinc.com/) - Launchable uses machine learning to predict which tests are likely to fail and selects a subset to run in CI. - [Qodo](https://qodo.ai/) - Qodo (formerly CodiumAI) is an AI code integrity platform that generates unit tests, suggests code improvements, and helps developers verify behavior.
